# 240回転ノート iPad向け変更（2026-09-27）

クラウドのセッションで、公開中の「240回転ノート」（https://claude.ai/artifact/Wt3j4e7hfUsZEczYMCsv4c）を
iPad向けに更新した（公開版 Version 96）。手元の元ファイル（build.py など）から作り直すときは、
この変更を取り込んでから公開すること。取り込まずに公開すると、iPad向けの変更が消える。

## 変更点
- ペンで書く（浮かぶ計算用紙 `padwin`・画面分割の白紙 `wsPad` で共通の `inkHook`）
  - ペンで書き、指はスクロール。ペンを一度も使っていない間だけ指でも書ける（`localStorage.inkPen`）
  - iPadのSafariでペンを引くとページが動くのを、`touchstart/touchmove` で `touchType === "stylus"` のときだけ止める
  - 線の太さは一定（`INK_W = 2.2`、筆圧なし）。書いた分だけ足して描く
  - 浮かぶ計算用紙のキャンバスを画面の細かさ（devicePixelRatio、最大2）に合わせた
  - 消しゴムは、なぞった線を1本まるごと消す（前の「白で塗る」消しゴムの跡はそのまま描く）
  - 1つ戻すは操作の記録で戻す（消しゴムで消した線も戻る）。2本指でトントンでも戻す
  - 画面分割の白紙の「✋ 動かす」ボタンは削除
- 数字のテンキー：`inputmode="numeric"/"decimal"` の欄は `inputmode="none"` にして、自前のテンキー（`#kpad`）を出す。
  帯を引っぱって動かせる。位置は縦横ごとに `localStorage` に覚える
- iPadの縦向き・横向き
  - `NARROW()`（幅700未満 または 縦向き）で、窓を下半分に出す・もう一方をたたむ（前のスマホ用の動き）
  - 横向きの初めの位置は右側に上下（上：採点、下：計算用紙）
  - 窓の位置は `padwin:p` / `padwin:l` / `trainwin:p` / `trainwin:l` に向きごとに覚える。回したら `winFit()` で収め直す
  - 画面分割は縦向きなら `t2`/`tb` で始める。並べ方は向きごとに覚える（`ws:<key>:p`）。境目は2回タップで半分ずつ
  - 窓の右下のつまみを 36px に、画面分割の境目は触れる範囲を左右（上下）12px 広げた
- 削除：矢印キー・Esc・Enter の操作、マウスホイール（ページめくり・拡大）、ダブルクリックでの拡大
- `:hover` の色は `@media (hover:hover)` の中へ（iPadでタップ後に色が残らないように）

## ファイル
- `patch.py`：公開版（orig.html）にこの変更を当てるスクリプト（どこを差し替えたかの記録）
- `ink.js`：ペンで書く共通部分
- `kpad.js` / `kpad.css`：テンキー
